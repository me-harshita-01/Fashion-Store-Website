# StyleHub – Fashion Store Website

StyleHub is a simple and modern fashion e-commerce website created as a first-year Web Development college project. It showcases fashionable clothing, footwear, and accessories with a clean and minimal design.

## 🌟 Features

- Modern and attractive homepage
- Navigation bar with brand name and links
- Promotional hero banner
- Product categories
- Product cards with images, names, and prices
- Add to Bag button
- Attractive hover effects
- Responsive design for mobile and desktop screens

## 🛠️ Technologies Used

- **HTML5** – For creating the website structure.
- **CSS3** – For styling, layouts, and responsive design.
- **JavaScript** – For basic button interaction.

## 📁 Project Structure

```text
fashion-store-website/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file.
4. Run it using the Live Server extension or open it directly in your browser.

## 🎯 Project Objective

The main objective of this project is to understand the basics of front-end web development and learn how to create a responsive and visually appealing e-commerce website using HTML, CSS, and JavaScript.
